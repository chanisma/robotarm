# SO-101 로봇팔과 LeRobot

조사일: 2026-10-11. 출처는 맨 아래에 있다. ⚠️ 표시는 확인되지 않은 값이다.

## 1. 하드웨어
| 항목 | 내용 |
|---|---|
| 구성 | 모터 6개 = 관절 5개 + 집게 1개. 흔히 "6-DOF 팔"이라고 부른다. ID 1–6: `shoulder_pan`, `shoulder_lift`, `elbow_flex`, `wrist_flex`, `wrist_roll`, `gripper` |
| 모터 | Feetech **STS3215** 버스 서보, 한 바퀴 4096 단위 |
| 팔로워(움직이는 팔) | 6개 모두 감속비 1/345. 7.4 V 버전은 6 V에서 정지 토크 16.5 kg·cm, 12 V 버전은 30 kg·cm (12 V 5 A 이상 전원 필요) |
| 리더(사람이 잡고 움직이는 팔) | 감속비가 관절마다 다르다 (1/191, 1/345, 1/147). 항상 7.4 V |
| 구동 보드 | Waveshare 버스 서보 어댑터 (약 $10.6). 점퍼를 "B"(USB) 쪽에 둔다 |
| 가격(부품, 3D 프린트 제외) | 팔로워 약 $122, 리더+팔로워 약 $230. 조립 키트는 Seeed, WowRobo, PartaBot 등에서 판매 ⚠️ 가격 미확인 |
| 작업 공간(시뮬 측정) | 최대 수평 거리 약 47 cm. **집게를 수직 아래로**: 높이 5 cm에서 13–34 cm, 10 cm에서 19–28 cm, 12 cm 이상은 손목 한계로 불가 (조금 기울이면 15 cm까지) |

## 2. LeRobot 소프트웨어
- 설치: `pip install "lerobot[feetech]"` (**Python 3.12 이상**, PyTorch 2.10 이상 권장). Windows에서는 포트가 COM 번호로 잡힌다.
- 팔 하나 제어:
```python
from lerobot.robots.so_follower import SO101Follower, SO101FollowerConfig
robot = SO101Follower(SO101FollowerConfig(port="COM3", id="my_arm"))   # use_degrees=True 가 기본
robot.connect()                    # 저장된 보정 파일이 없으면 보정 절차 실행
obs = robot.get_observation()      # {"shoulder_pan.pos": 도, ..., "gripper.pos": 0~100}
robot.send_action({"elbow_flex.pos": 30.0})   # 실제로 보낸(범위로 잘린) 값을 돌려줌
robot.disconnect()
```
- 단위: 관절은 **도(°)**, 집게는 **0 = 닫힘 ~ 100 = 열림**.
- 옵션: `max_relative_target`(한 번에 움직일 최대 각도, 안전용). 연결할 때 집게 최대 토크는 50 %로 제한된다.
- 명령줄 도구:
  - `lerobot-find-port`: 포트 찾기
  - `lerobot-setup-motors`: 모터 ID 설정
  - `lerobot-calibrate --robot.type=so101_follower --robot.port=COM3 --robot.id=my_arm`: 보정
- 보정 순서: 팔을 각 관절의 가운데쯤에 두고 Enter → 손목 돌림을 뺀 모든 관절을 끝에서 끝까지 움직인다. 보정 파일은 `~/.cache/huggingface/lerobot/calibration/robots/so_follower/<id>.json`에 저장된다.
- 예전 경로 `lerobot.robots.so101_follower`는 더 이상 없다. 지금은 `so_follower`다.

## 3. 시뮬레이터와 실제 팔의 대응
- 이 프로젝트의 시뮬 모델은 **MuJoCo Menagerie `robotstudio_so101`**이다. TheRobotStudio의 `so101_new_calib.xml`에서 유도됐고, 영점과 관절 범위가 같다. 집게에 단순 충돌 도형이 추가되어 물건을 집을 수 있다. 원본 모델은 메시의 볼록 껍질 때문에 두 턱 사이가 막혀 있어서 집을 수 없었다(직접 확인).
- 'new calib' 영점 = 관절 범위의 가운데. LeRobot도 자체 코드에서 `deg2rad`/`rad2deg`로 **오프셋 없이** 시뮬 각도와 변환한다. 그래서 `시뮬 rad = 실제 팔 ° × π/180`이다.
- 집게: LeRobot의 0–100 값과 시뮬 관절각(−10°–100°)을 **선형으로 근사해 대응**시켰다 ⚠️ (공식 대응식 없음).
- 액추에이터: 위치 제어, kp 998, 최대 힘 2.94 Nm (시뮬 모델 값). 실제 서보의 게인과 1:1로 같지는 않다.

| 관절 | 범위(°, 시뮬 기준) | + 방향 (팔을 앞으로 쭉 편 0° 자세 기준, 시뮬 측정) |
|---|---|---|
| shoulder_pan 허리 | −110 ~ 110 | 오른쪽으로 (위에서 보면 시계 방향) |
| shoulder_lift 어깨 | −100 ~ 100 | 앞·아래로 숙임 |
| elbow_flex 팔꿈치 | −97 ~ 97 | 아래로 접힘 |
| wrist_flex 손목 | −95 ~ 95 | 집게가 아래로 숙여짐 |
| wrist_roll 손목 돌림 | −157 ~ 163 | 집게가 자기 축으로 회전 |
| gripper 집게 | 0 ~ 100 % | 열림 |
