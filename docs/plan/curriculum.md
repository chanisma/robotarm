# 로봇팔 교육 과정 (고등학생, 기초 Python)

robotdog(Lite3) 과정과 같은 방식이다. **값의 뜻을 눈으로 보고(조작 패널) → 같은 동작을 코드로 쓰고(스튜디오) → 실제 팔로 옮긴다(LeRobot)**.

| 차시 | 샘플 | 핵심 개념 | 조작 패널 | 확인한 결과 (시뮬) |
|---|---|---|---|---|
| A1 | `a1_one_motor.py` | 서보 모터, 목표 각도와 현재 각도 | ① 관절 | 네 관절 모두 목표 각도에 도달. 범위 밖 값은 범위 끝에서 멈춤 |
| A2 | `a2_poses.py` | 자세 = 각도 묶음, 동작 = 자세 잇기, 반복문 | 접기/준비/영점 버튼 | 손 흔들기 3회, 고개 끄덕이기 |
| A3 | `a3_forward.py` | 정기구학: 각도 → 집게 끝 위치 | ① 관절 + 옆·위 그림 | 팔꿈치 0→90°: 끝이 호를 그림 (높이 42→2 cm). 허리를 돌리면 높이 21 cm 그대로 원을 그림 |
| A4 | `a4_inverse.py` | 역기구학: 위치 → 각도, 닿는 범위 | ② 집게 끝 옮기기 (끌기) | 8 cm 정사각형을 공중에 그림 (오차 1 mm 이내). 닿지 않는 곳은 이유와 함께 오류 |
| A5 | `a5_pick_place.py` | 순서 설계, 센서(잡았는지) 확인, 함수 | ③ 집기 | 빨간 상자를 집어 목표 구역 중심 2 cm 이내에 놓음 |
| 연결 | `lerobot_style.py` | 실제 팔과 같은 공식 형식 | 코드 상자의 "LeRobot 공식 형식" 줄 | `send_action`이 범위 밖 요청을 잘라서 돌려줌 (150° → 96.8°) |

## 실제 팔로 옮기기
1. 시뮬에서 `arm.robot.send_action({...})`(공식 형식)으로 동작을 완성한다.
2. 실제 팔: `pip install "lerobot[feetech]"` → `lerobot-find-port` → `lerobot-calibrate`.
3. 코드의 `robot = arm.robot`을 `SO101Follower(SO101FollowerConfig(port=..., id=...))` + `connect()`로 바꾼다. 처음에는 `max_relative_target=10`으로 한 번에 움직이는 각도를 제한한다.
4. 주의: 실제 팔에는 `move_tip`(역기구학)과 상자 위치(`find`)가 없다. 실물로 옮기려면 역기구학을 LeRobot의 kinematics 모듈로 다시 연결하고, 물체 위치는 카메라 등으로 따로 구해야 한다.

## robotdog 과정과 이어지는 점
| 개념 | 로봇개 (Lite3) | 로봇팔 (SO-101) |
|---|---|---|
| 모터 하나 | J1 관절 하나 | A1 서보 하나 |
| 기구학 | J3 다리 (관절 2개, 평면) | A3·A4 팔 (관절 5개, 3차원, 집게 방향) |
| 안정성·힘 | J4 무게중심·지지 다각형 | 모터 부하(최대 힘 대비 %), 집게로 쥐는 힘 |
| 공식 인터페이스 | 딥 로보틱스 `SetJointCommand` (12×5, rad) | LeRobot `send_action` (키·도) |
